# Installation

```bash
npm install @framelet/solid
```

Other package managers:

```bash
pnpm add @framelet/solid
yarn add @framelet/solid
bun add @framelet/solid
```

## Peer dependencies

| Package    | Supported versions |
| ---------- | ------------------ |
| `solid-js` | 1.x, 2.x           |

`@framelet/core` is included as a dependency and re-exported.
