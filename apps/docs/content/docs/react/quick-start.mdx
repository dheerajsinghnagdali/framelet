# Quick start

## Compound components

```tsx
import { Framelet } from '@framelet/react';

export default function App() {
  return (
    <Framelet.Root width={640} height={480}>
      <Framelet.Viewport>
        <Framelet.Canvas />
        <Framelet.EmptyState>Drop an image here</Framelet.EmptyState>
      </Framelet.Viewport>
      <Framelet.Controls>
        <Framelet.FileInput />
        <Framelet.UploadTrigger />
        <Framelet.CropTrigger />
        <Framelet.ApplyCropTrigger />
        <Framelet.RotateTrigger />
        <Framelet.UndoTrigger />
        <Framelet.RedoTrigger />
      </Framelet.Controls>
      <Framelet.FilterControl />
      <Framelet.AdjustmentList />
    </Framelet.Root>
  );
}
```

## Load an initial image

```tsx
<Framelet.Root src="/photo.jpg" width={640} height={480}>
  {/* parts */}
</Framelet.Root>
```

The `src` prop accepts any `ImageSource`, including URLs, `File`, `Blob`, `HTMLImageElement`, and `ImageData`.

## Headless hook

```tsx
import { useFramelet } from '@framelet/react';

function Editor() {
  const api = useFramelet();

  return (
    <>
      <input
        type="file"
        onChange={(event) => {
          const file = event.target.files?.[0];
          if (file) void api.loadImage(file);
        }}
      />
      <label {...api.getFilterControlProps()}>
        Filter
        <select {...api.getFilterSelectProps()} />
      </label>
      <button onClick={api.undo}>Undo</button>
      <button onClick={api.redo}>Redo</button>
    </>
  );
}
```

See [Custom UI](/docs/react/custom-ui) for complete canvas and prop-getter examples.
