# Custom UI

Use `useFramelet` when you want complete control over markup and styling. Prop getters provide the state and handlers while leaving the elements to you.

```tsx
import { useFramelet, FILTER_IDS } from '@framelet/react';

export function MyEditor() {
  const api = useFramelet();

  return (
    <div {...api.getRootProps({ className: 'editor' })}>
      <div {...api.getViewportProps()}>
        <canvas {...api.getCanvasProps()} />
      </div>

      <input {...api.getFileInputProps()} />
      <button {...api.getUploadTriggerProps()}>Upload</button>

      <label {...api.getFilterControlProps()}>
        Filter
        <select {...api.getFilterSelectProps()}>
          {FILTER_IDS.map((id) => (
            <option key={id} {...api.getFilterOptionProps({ id })} />
          ))}
        </select>
      </label>

      <button {...api.getRotateTriggerProps()}>Rotate</button>
      <button {...api.getFlipHorizontalTriggerProps()}>Flip H</button>
      <button {...api.getUndoTriggerProps()}>Undo</button>
      <button {...api.getRedoTriggerProps()}>Redo</button>
    </div>
  );
}
```

Every getter merges your props with the internal ones. Your event handlers run first, and calling `preventDefault()` stops the internal handler.

## Compound components

For structured UIs, compose `Framelet.*` parts instead. They read the same state from context and apply the matching prop getter.

```tsx
import { Framelet } from '@framelet/react';

export function MyEditor() {
  return (
    <Framelet.Root>
      <Framelet.Viewport>
        <Framelet.Canvas />
        <Framelet.EmptyState>Drop an image here</Framelet.EmptyState>
      </Framelet.Viewport>

      <Framelet.Controls>
        <Framelet.FileInput />
        <Framelet.UploadTrigger>Choose image</Framelet.UploadTrigger>
        <Framelet.CropTrigger />
        <Framelet.ApplyCropTrigger />
        <Framelet.CancelCropTrigger />
        <Framelet.RotateTrigger />
        <Framelet.UndoTrigger />
      </Framelet.Controls>

      <Framelet.AdjustmentList />
    </Framelet.Root>
  );
}
```

Parts can be omitted or reordered. The preset editor in `apps/demo` is one composition of these parts. See [Anatomy](/docs/react/anatomy) for styling selectors.

## Direct editor access

The core editor is still available when you need to render or export outside React's render cycle.

```tsx
function ExportButton() {
  const api = useFramelet();

  return (
    <button
      onClick={async () => {
        const blob = await api.exportImage({ format: 'image/png' });
        console.log(blob);
      }}
    >
      Export
    </button>
  );
}
```
