# @framelet/react

React bindings for Framelet. The package is headless: it provides the `useFramelet` hook, compound `Framelet.*` parts, and prop getters. It re-exports the full core API.

A batteries-included preset editor lives in the `apps/demo` application, not in this package.

## Install

```bash
npm install @framelet/react
```

Peer dependencies: React 18 or React 19.

## Two ways to use Framelet

### Compound components

```tsx
import { Framelet } from '@framelet/react';

export default function App() {
  return (
    <Framelet.Root src="/photo.jpg" width={640} height={480}>
      <Framelet.Viewport>
        <Framelet.Canvas />
        <Framelet.EmptyState>Drop an image</Framelet.EmptyState>
      </Framelet.Viewport>
      <Framelet.Controls>
        <Framelet.FileInput />
        <Framelet.UploadTrigger />
        <Framelet.RotateTrigger />
      </Framelet.Controls>
    </Framelet.Root>
  );
}
```

### Hook

```tsx
import { useFramelet } from '@framelet/react';

function MyEditor() {
  const api = useFramelet();
  return <button onClick={() => api.loadImage('/photo.jpg')}>Load</button>;
}
```

## Exports

- `useFramelet` — headless state/actions hook with prop getters.
- `Framelet` — compound component namespace.
- `frameletAnatomy` / `frameletParts` — part selectors and attributes.
- Everything from `@framelet/core`.
