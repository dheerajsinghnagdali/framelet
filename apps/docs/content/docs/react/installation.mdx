# Installation

```bash
npm install @framelet/react
```

Other package managers:

```bash
pnpm add @framelet/react
yarn add @framelet/react
bun add @framelet/react
```

## Peer dependencies

| Package     | Supported versions |
| ----------- | ------------------ |
| `react`     | 18.x, 19.x         |
| `react-dom` | 18.x, 19.x         |

`@framelet/core` is installed as a dependency and its API is re-exported.

## TypeScript

React 18+ and TypeScript 5+ are recommended. The package ships declarations with `exports` conditions for ESM and CommonJS.
