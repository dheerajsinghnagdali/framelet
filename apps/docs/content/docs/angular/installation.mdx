# Installation

```bash
npm install @framelet/angular
```

Other package managers:

```bash
pnpm add @framelet/angular
yarn add @framelet/angular
bun add @framelet/angular
```

## Peer dependencies

| Package         | Supported versions           |
| --------------- | ---------------------------- |
| `@angular/core` | 18.x, 19.x, 20.x, 21.x, 22.x |

`@framelet/core` is installed as a dependency and re-exported.
